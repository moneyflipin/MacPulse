# MacPulse

MacPulse — нативный монитор состояния Mac для строки меню macOS.  
Приложение показывает главные метрики системы без тяжелого фонового процесса и помогает быстро понять, что происходит с Mac прямо сейчас.

## Что умеет

- показывает CPU, память, температуру, батарею и состояние диска прямо в строке меню
- открывает отдельный центр управления с обзором, трендами, процессами, батареей, сенсорами и настройками
- показывает самые тяжелые процессы по CPU и памяти
- отслеживает питание батареи: зарядка, мощность в ваттах, время до полной зарядки или разрядки
- хранит локальную историю метрик и событий между перезапусками
- дает понятные инсайты по памяти, нагреву, swap и общей нагрузке
- поддерживает onboarding, автозапуск и системные уведомления
- использует светлую и темную тему и нативные материалы macOS

## Для обычного пользователя

Скачивай не `Source code`, а готовую собранную версию приложения из `Releases`.

### Как установить

1. Открой страницу релизов:  
   [https://github.com/moneyflipin/MacPulse/releases](https://github.com/moneyflipin/MacPulse/releases)
2. Скачай файл `MacPulse-<версия>.dmg`
3. Открой DMG
4. Перетащи `MacPulse.app` в `Applications`
5. Извлеки и удали DMG после установки

Важно:

- `Source code (zip)` и `Source code (tar.gz)` — это архивы исходников, а не установщик
- для установки нужен именно готовый `DMG`
- пока приложение не notarized через Apple Developer ID, macOS может попросить первый запуск через `Правый клик -> Открыть`

## Что внутри приложения

### Строка меню

- несколько режимов информативности: компактный, сбалансированный, подробный
- пресеты отображения: иконки и текст, только иконки, только текст
- компактный popover с быстрыми действиями

### Центр управления

- обзор состояния системы
- история и тренды
- топ процессов
- батарея и питание
- сенсоры температуры
- внешний вид и режимы приложения
- системные настройки приложения

### Диагностика

- история CPU, памяти, температуры и батареи
- события нагрузки: рост swap, давление памяти, нагрев, дефицит диска
- безопасные действия по процессам: показать приложение, открыть в Finder, открыть Activity Monitor, мягко завершить

## Безопасность и приватность

- приложение работает локально
- системные данные не отправляются во внешние сервисы
- действия с процессами выполняются только по явному запросу пользователя
- история сохраняется локально на устройстве

## Технологии

- `SwiftUI`
- `AppKit`
- `NSStatusItem` и `NSPopover`
- `IOKit`
- `Mach`
- Objective-C bridge для HID-сенсоров температуры

## Требования

- macOS 14 или новее
- Xcode Command Line Tools или Xcode для локальной сборки

## Запуск из исходников

```bash
swift build
./.build/arm64-apple-macosx/debug/MacPulse
```

Можно также открыть `Package.swift` в Xcode и запускать проект как обычное macOS-приложение.

## Сборка `.app`, `.zip` и `.dmg`

```bash
zsh scripts/package_app.sh 1.1.0 10
```

После этого локально появятся:

- `dist/MacPulse.app`
- `dist/MacPulse-1.1.0.zip`
- `dist/MacPulse-1.1.0.dmg`

`DMG` — основной формат для установки и отправки другим людям.

## Структура проекта

- `Sources/MacPulse/App` — запуск приложения и жизненный цикл
- `Sources/MacPulse/Models` — модели состояния, настроек и продуктовой логики
- `Sources/MacPulse/Services` — сбор и хранение метрик
- `Sources/MacPulse/Support` — menu bar, форматирование, системные действия и интеграции
- `Sources/MacPulse/Views` — интерфейс центра управления, onboarding и popover
- `Sources/MacPulseBridge` — bridge для температурных HID-сенсоров
- `scripts` — упаковка, иконка приложения и генерация фона для DMG

## Ограничения

- часть температурных сенсоров зависит от модели Mac и доступности системных HID-сервисов
- уведомления и автозапуск требуют разрешений и системной поддержки macOS
- приложение пока не notarized
