# MacPulse

Нативное menu bar приложение для macOS, которое показывает основные характеристики MacBook без тяжелого фонового процесса:

- загрузку CPU
- память
- свободное место на диске
- состояние батареи, циклы и износ
- температуры с доступных датчиков Apple Silicon
- термальное состояние системы и режим энергосбережения
- историю метрик и мини-графики
- timeline причин и событий нагрузки
- настраиваемую информативность строки в верхнем баре
- пресеты menu bar и стили строки: иконки + текст, только иконки, только текст
- адаптивную частоту обновления для меньшей нагрузки на систему
- отдельное окно управления при запуске приложения
- системные glass/material эффекты и поддержку светлой/темной темы
- топ процессов по CPU и памяти
- раскладку памяти по категориям
- swap и оценку memory pressure
- Smart Insights и безопасные one-click helpers
- Battery Coach с рекомендациями
- session-профили приложений с пиками CPU/RAM
- уровни интерфейса: базовый, умный, профи
- экспорт снимка здоровья Mac в текстовый отчет
- onboarding для первого запуска
- отдельное окно `О MacPulse`
- launch at login и настройки поведения окна на старте
- системные уведомления о важных событиях
- сохранение истории и событий между перезапусками
- экспорт отчета в `txt` и `markdown`

## Технологии

- `SwiftUI` для интерфейса
- `NSStatusItem` и `NSPopover` для полностью управляемой строки menu bar
- `IOKit` и `Mach` для легкого чтения системных метрик
- небольшой Objective-C bridge для температурных HID-сенсоров

## Структура

- `Sources/MacPulse/App` — запуск приложения
- `Sources/MacPulse/Services` — сбор метрик
- `Sources/MacPulse/Views` — интерфейс меню и карточек
- `Sources/MacPulseBridge` — bridge для температурных сенсоров

## Что уже есть

- компактная строка статуса в верхнем баре
- несколько режимов строки menu bar: минимум, баланс, подробно
- отдельное окно управления с разделами: обзор, инсайты, тренды, процессы, батарея, menu bar, сенсоры, внешний вид
- компактный menu bar popover с быстрыми действиями и нативной строкой через `NSStatusItem`
- автообновление с адаптивным замедлением на батарее и в low power mode
- история значений CPU, памяти, температуры и батареи
- история причин: давление памяти, swap, нагрев, дефицит диска
- блоки лидеров по CPU и памяти среди процессов
- безопасные действия по процессам: открыть в Monitor, показать приложение, показать файл, мягко завершить
- раскладка памяти по категориям: приложения, wired, кэш, сжатая, swap
- группировка сенсоров по типам и выбор глубины отображения
- режимы продукта: работа, создание, от батареи, диагностика
- Smart Insights, Battery Coach и session-профили приложений
- fallback, если часть сенсоров недоступна
- onboarding с выбором режима, профиля и системных интеграций
- app-раздел с автозапуском, уведомлениями и повторным onboarding
- отдельное окно `О MacPulse`
- сохранение истории CPU/памяти/температуры/батареи и событий между перезапусками
- уведомления macOS по важным событиям
- экспорт отчетов в `txt` и `markdown`
- закрытие окна центра управления не завершает menu bar часть приложения

## Как запустить

1. Собрать пакет:
   `swift build`
2. Запустить бинарник:
   `./.build/arm64-apple-macosx/debug/MacPulse`

Можно также открыть `Package.swift` в Xcode и запускать приложение оттуда как обычный macOS target.

## Как собрать `.app` для друга

1. Запусти упаковку:
   `zsh scripts/package_app.sh 1.0.0 1`
2. Готовое приложение появится в:
   `dist/MacPulse.app`
3. Готовый архив для отправки появится в:
   `dist/MacPulse-1.0.0.zip`

Скрипт собирает `Release`, формирует нормальный `.app`, делает ad-hoc подпись и упаковывает его в `zip`.

Важно:

- если друг скачает архив из мессенджера или браузера, macOS может показать предупреждение, потому что приложение не notarized через Apple Developer ID
- самый беспроблемный вариант передачи: `AirDrop`
- если приложение было скачано, первый запуск можно сделать через `Правый клик -> Открыть`

## Ограничения текущей среды

- проект чисто собирается через `swift build`
- приложение дополнительно проверено живым запуском бинарника без мгновенного крэша
- автоматические тесты в этой среде не настроены, потому что установленный Command Line Tools toolchain не дает нормальный test framework для Swift Package
- часть температурных сенсоров зависит от модели Mac и доступности приватных HID-сервисов
